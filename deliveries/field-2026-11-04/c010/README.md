# C010 课堂储物标签 — 使用说明 / Classroom Storage Labels — README

幼儿园／小学教室用的可填写储物标签：贴在盒子、抽屉、美术材料和共享用品上。
老师先在电脑上打字填好，再打印、裁剪、粘贴，不用手写。

Fillable storage labels for kindergarten / primary classrooms. Type the text
on your computer first, then print, cut and stick — no handwriting needed.

## 文件 / Files

- `C010-Classroom-Storage-Labels_A4.pdf` — A4 版（210 × 297 mm）
- `C010-Classroom-Storage-Labels_Letter.pdf` — US Letter 版（8.5 × 11 in）
- 每页 8 个标签：分类名已预印（中英双语），下方白框是可填写栏，填具体名称。

One file per paper size. Each page has 8 labels; the category name is
pre-printed (Chinese + English) and the white box under it is a fillable
field for the specific item name.

## 怎么用 / How to use

1. 用支持表单的 PDF 阅读器打开与你纸张对应的那一份文件。
2. 点白框，输入文字（中文、英文、数字都可以）。
3. 打印：**必须选 100% / Actual size（实际大小），不要选「适合页面 / Fit to page」**——缩放会让标签尺寸对不上。
4. 沿标签框边缘裁剪后粘贴。

1. Open the file that matches your paper in a PDF reader that supports forms.
2. Click a white box and type (Chinese, English and digits all work).
3. Print at **100% / Actual size — do not use "Fit to page"**, or the labels
   will come out smaller than designed.
4. Cut along the label outlines and stick.

## 字数上限（重要）/ Character limit (important)

- 每个白框是单行栏：**每行最多 16 个汉字**，英文约 **35 个字符**可以完整显示。
- 超过上限的文字不会报错，但超出部分在显示和打印时会看不见（被裁掉），
  请改用更短的说法或缩写。

Each white box is a single-line field: **up to 16 Chinese characters**, or
about **35 English characters**, display in full. Longer text is not
rejected, but the overflow will not be visible on screen or in print —
please shorten or abbreviate it.
